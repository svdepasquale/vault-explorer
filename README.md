# vault-explorer

Local graphical explorer for the [knowledge-vault](https://github.com/svdepasquale/knowledge-vault): the link graph Obsidian used to draw, plus a timeline, the vault's composition, health checks and a recall lens — read-only, served on `127.0.0.1`.

```bash
npm ci && npm run build
npm start -- --vault ~/projects/knowledge-vault
```

Full documentation lands with the remaining views.
